# Screenshots and images

Put documentation images in this folder (PNG, JPG, SVG, WebP, etc.).

## Expected placeholders referenced by the docs

| File | Used by |
|------|---------|
| `rigidbody-inspector.png` | `docs/api-reference/rigidbody-component.md` |

After adding a file, reference it from Markdown with the site baseurl:

```markdown
![Alt text]({{ site.baseurl }}/assets/images/your-file.png)
```
